# TOKEN

Landing page e backend inicial para a marca independente TOKEN.

## Rodar localmente

```bash
pip install -r requirements.txt
python main.py
```

## Estrutura

- `main.py` - backend Flask e fluxo do briefing para WhatsApp
- `templates/index.html` - landing page principal
- `static/css/style.css` - identidade visual e responsividade

## Ajuste rápido

Defina a variável de ambiente `TOKEN_WHATSAPP_NUMBER` com o número real do WhatsApp antes de publicar.
